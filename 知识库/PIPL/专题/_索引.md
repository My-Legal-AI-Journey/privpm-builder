# PIPL 专题索引

## 入库原则

- **不删减**：专题全文按用户粘贴入库；无法还原的 `[图片]` /「暂时无法在飞书文档外展示」保留占位。
- **图片**：能解析的表/图写入正文 Markdown，**不**使用 `专题/assets/`。
- **互链**：条文「参见专题」已改为相对路径；各专题文首有「相关条文」回链（见下「互链状态」）。
- **对人路径**：汇报「仍缺」时用知识库树路径：`《个保法》注释 → 第N条「主题」 → 专题「名称」 → 子页「名称」`；有飞书/语雀 URL 则另附；**禁止**只报本地磁盘路径。
- **附件**：正文只保留文件名引用；实体入附件目录后在下表勾选「到库」。
